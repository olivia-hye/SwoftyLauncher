# 1.7.28

Swofty Launcher for F1 25 1.7.28 makes replays and flashbacks smooth again with fuel mix addons.

## Addons

- With an addon that changes fuel mixes, such as Rich Fuel Mix, replays and flashbacks ran at a few frames a second. Every replay frame wrote each car's fuel mix values again and restarted its mix. The launcher now writes a car's values only when they change, once per car per frame.
