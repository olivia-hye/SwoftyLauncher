# 1.7.26

Swofty Launcher for F1 25 1.7.26 fixes the race fuel in Progressive Career seasons before 2026.

## Addons

- In a Progressive Career season before 2026, each session used the 2026 cars' fuel use per lap with the earlier season's fuel loads, so cars burned about a quarter less fuel than planned and finished races with too much left, and lowering it in the strategy screen didn't help. The launcher now writes a track's fuel use at a session only when an addon set it, so Progressive's fuel stays as it set it. Track addons that set their own fuel use are unchanged.
