# 1.7.24

Swofty Launcher for F1 25 1.7.24 makes the first Play on a new install go through.

## Launcher

- On a new install, **Accept and launch** in the **Modded play runs offline** dialog now goes on to the **Notice** shown before the first launch. Before, it saved your consent but then closed the Notice straight away, so the offline play dialog stayed open and pressing it again did nothing. **Launch** in the Notice had the same problem whenever Play had something else to show first. If you're stuck on an older version, press **Cancel**, then **Play**, then **Launch**.
