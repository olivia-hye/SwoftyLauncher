# 1.7.22

Swofty Launcher for F1 25 1.7.22 removes the freeze of two to five seconds when a session starts with many addons on.

## Performance

- Starting a session no longer freezes the game for two to five seconds while the core checks which cars the AI teams use. The change in 1.7.20 only helped where checking the game's memory is quick, as in a stock install; with many addons each check still took about a tenth of a second, and a session start runs 20 to 40 of them. The check now reads the game's memory directly, guarded against a bad pointer. In testing with every Classic Seasons year and Progressive Career on, 20 checks took under a millisecond in all. A check that still takes more than 5 ms is noted in `loader.log` as `[session] name hash decision took`, up to four times a session.
