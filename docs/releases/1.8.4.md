# 1.8.4

Swofty Launcher for F1 25 1.8.4 removes the frame hitches Windows players saw several times a second with Rich Fuel Mix on and as cars crossed the start/finish line. It also fixes **Play** refusing an EA app copy whose folder name has letters such as ö, ł or ü.

## Performance

- The launcher checks that the game's memory is safe to read before it touches a car. On Windows, a check inside the game's large memory areas could take about 10 ms, and the per-frame car work used by Rich Fuel Mix repeated it four times a second. The answer is now kept for a few seconds and dropped when a session starts or ends.
- The same check in the lap-crossing guard no longer repeats for every car crossing the line within a few seconds of each other.

## EA app

- **Play** stopped with **The EA app has F1 25 in another folder** for an EA app copy in a folder such as `D:\Yeni klasör\F1 25`, even though the game was never moved. The launcher misread the folder's name from the EA app's record, so the two never matched. It now reads it correctly, and a record whose name it can't read no longer stops **Play**.
