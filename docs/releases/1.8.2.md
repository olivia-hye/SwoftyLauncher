# 1.8.2

Swofty Launcher for F1 25 1.8.2 cuts the per-frame cost of offering every fuel mix on the MFD, which slowed replays and flashbacks with Rich Fuel Mix, and frees car package ids that saved careers held for addons that no longer add those packages.

## Performance

- With Rich Fuel Mix's **Offer every mix on the MFD** on, the launcher read the game's fuel mix table once per car and mix on every frame, even when nothing had changed. It now reads the table once per frame and only writes the mixes the game locked again, so replays and flashbacks no longer lose time to it.
- The log names the launcher's own per-frame work by part (career, cars, session points), so a slow frame shows which part it was.

## Addons

- A saved career no longer keeps car package ids for itself. When an addon adds fewer car packages than before, the ids it no longer uses are free for other car addons, so big season packs are less likely to stop Play with "has no free stat_id".
