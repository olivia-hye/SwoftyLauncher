# 1.8.3

Swofty Launcher for F1 25 1.8.3 removes the per-frame work that made replays and flashbacks drop frames with Rich Fuel Mix, and other addons that set car values, turned on.

## Performance

- During replays and flashbacks the game rebuilds every car each frame, and the launcher re-read and re-applied every addon's car values for each of them. It now re-applies a car's values only when something they depend on has changed, and otherwise just checks that the game hasn't reset them. With Rich Fuel Mix on, this work drops from several milliseconds a frame to a few microseconds.
- A value the game resets is still put back on the next frame.
- The log breaks the launcher's car work into its parts (profiles, applying values, the fuel mix unlock), so a slow frame shows which one it was.
